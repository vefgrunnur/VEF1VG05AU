#### Process

* Create a website about a band or musician.
* The installation of the web series is in our hands.

The web series should include the following items

1. Information about a band or musician.
* Reference material is optional (_may be in English_)
1. Movie downloaded from Youtube or other comparable streaming services
* The movie must be in a **flexible iframe** frame
1. Insert a song in the `audio' category and/or access a playlist from a streaming provider
1. Insert a map from [maps.google.com]() to the website that points to any location discussed in the introductory text.
* If it is not suitable, you can put a map in the footer together with your information, and the map can point to the Technical College on Hateigsvegur
1. Finish
* HTML 5 syntax (_Semantics_)
* CSS neatly laid out, each command indented on a separate line
