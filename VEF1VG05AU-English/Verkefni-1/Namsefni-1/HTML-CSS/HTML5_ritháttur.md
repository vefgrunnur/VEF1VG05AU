# HTML5 font

Using semantic HTML5 tags such as `<header>`, `<main>`, `<section>`, `<article>`, `<aside>` and `<footer>` is one of the most important foundations of modern web design. 

### **1. 
One of the most important advantages of this method is that it improves **accessibility** of the website. 
* **`<main>`** tells the document reader where the main content of the page starts, allowing the user to skip menus directly.
* **`<nav>`** (often inside the header) and **`<footer>`** help users to understand where they are and where to find information about contacts or navigation systems.

### **2. 
The use of these tags is important for **search engine optimization (SEO)**. 
* Content inside **`<article>`** is interpreted as independent content (e.g. blog post or news), which makes it easier for search engines to sort it correctly.
* **`<aside>`** tells search engines that the content is not the main topic, which helps them focus on more important text.

### **3. 
HTML is used to **organize the structure of the website** and its content in an easy way.
* By using an infinite number of `<div>` tags, HTML5 tags allow developers to immediately see what role each part of the page has.
* This makes collaboration between programmers easier and speeds up when you need to make changes to the code.
