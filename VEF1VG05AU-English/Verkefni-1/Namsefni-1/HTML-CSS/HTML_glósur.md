# Main HTML elements and their roles

HTML (HyperText Markup Language) is used to organize the structure and content of web pages. 

### 1. Basic units for text and structure
* **`<h1>` to `<h6>`**: Used for **headings** on the website. 
* **`<p>`**: Used around **paragraphs**.
* **`<ul>`**: Used to create **irregular lists** (bullet lists).
* **`<li>`**: Used for each **list item** within a list.
* **Emphasis**: Elements such as `<em>` and `<strong>` (if the names are not specifically mentioned in the text of the sources, they are used for this purpose) are used to give text **emphasis or importance**.

### 2. Links and media
* **`<a>`**: Used to create **links** (links) that connect seeds or shelters.
* **`<img>`**: Used to display **images** in the filter.
* **`<video>`**: Used to insert and play **videos**.
* **`<audio>`**: Used to insert and play **audio files**.

### 3. Data and communication
* **`<table>`**: Used to create **data tables** to organize information into columns and rows.
* **`<form>`**: Used to create **forms** for communication with users.
* **`<input>`**: Used for various **input fields** (e.g. text boxes) inside forms.
* **`<button>`**: Used to create clickable **buttons**.

### 4. Planning and management
* **Metadata**: Information located in the head of the document and describing the **characteristics of the website** itself, such as the title.
* **Structuring documents**: HTML is basically used to **structure the entire document** and divide it into logical parts.
