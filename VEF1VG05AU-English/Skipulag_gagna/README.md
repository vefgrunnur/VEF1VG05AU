> An operating system controls how the computer works with files, folders, programs, and devices.

## Main Differences Between the Operating Systems

- **macOS:** Harmonized user interface, strong ecosystem with Apple devices and good built-in backup (Time Machine).
- **Windows:** The most common operating system on personal computers, with broad software and game support, and strong compatibility with Microsoft services.
- **Linux:** Open source software, very flexible environment, popular for programming and networking, but can require more technical skills.
