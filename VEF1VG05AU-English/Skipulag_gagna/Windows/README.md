## Introduction

In Windows, information is managed through a file system.

![Windows 11](explorer-11.png)

## Basic Concepts

- `File`: A unit that stores content, such as text, images, audio, or video.
- `Folder`: A container that holds files and other folders.
- `Location`: The path that shows where a file or folder is stored.

## Main Folders in File Explorer

- `Desktop`: Temporary files for quick access.
- `Documents`: Projects, reports, and other work files.
- `Downloads`: Files downloaded from the internet.
- `Pictures`, `Music`, `Videos`: Media storage folders.
- `This PC`: Overview of drives, disks, and core folders.

## Workflow for Handling Data

1. Open **File Explorer** (`Windows + E`).
2. Create a folder with **New Folder** for each project or topic.
3. Move files into the right folders using drag-and-drop.
4. Rename files with descriptive names, for example `project-math-2026.pdf`.
5. Use search in the top-right corner of File Explorer to find files.
6. Delete unnecessary files to `Recycle Bin` and empty it when you are sure.

## Best Practices

- Use one main folder per project or course.
- Avoid storing permanent data on `Desktop`.
- Use clear and consistent names for files and folders.
- Back up regularly to `OneDrive` or an external drive.

### Overview: Working with Data in Windows

- **File Explorer:** Main tool for browsing, moving, and organizing files.
- **User folder:** Contains `Desktop`, `Documents`, `Downloads`, and `Pictures`.
- **Search:** Quickly finds files by full or partial name.
- **Drag-and-drop:** Easy way to move or copy files between folders.
- **Delete data:** Files first go to `Recycle Bin` and can be restored before permanent deletion.

### Important Terms

- **OneDrive:** Microsoft cloud service for sync and backup across devices.
- **Recycle Bin:** Temporary storage for deleted files before permanent removal.

## Summary

Good data organization in Windows depends on proper folder structure, clear naming, and regular backups.

## Submitting Assignments in Inna

#### All assignments must be submitted in Inna.

Example: All files for Assignment 1 are placed in one folder and compressed into a **.zip file**.

### How to Compress Data into One `.zip` File

1. Open **File Explorer**.
2. Locate the folder or files you want to submit.
3. If there are multiple files, select all (`Ctrl + A` if needed).
4. Right-click the selected content.
5. Select **Compress to ZIP file** (or **Send to > Compressed (zipped) folder** on older versions).
6. Windows creates a `.zip` file in the same location.

### Submission Example

- `Assignment-1.zip`

### Good to Remember

- Put all assignment files in **one folder** before compressing.
- Rename the `.zip` file clearly before submission, for example `Name-Assignment1.zip`.

### Windows 11

- To open a `.zip` file, double-click it.

### Windows 10

- To work with compressed content, extract first.
- Right-click the `.zip` file and select **Extract All...**.
