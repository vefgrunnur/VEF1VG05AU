### Background taken from a photo

1. Create a _"Raster Mask"_
* selection menu -> _"Raster Mask"_ -> _"Add (Reveal all)"_ <br>
    ![Mynd 1](Freyr/Frey_Project-1.jpg)
* hit the keyboard `Control` + `f` <br>
    ![Mynd 2](Freyr/Frey_Project-2.jpg)
* Type _"Remove"_ in the input field and select _"Remove BG"_ <br>
    ![Mynd 3](Freyr/Frey_Project-3.jpg)
* This program clears the background
    ![Mynd 3](Freyr/Frey_Project-4.jpg)
2. Then save the image as a .png file
* Selection -> _"File"_ -> _"Export as"_ -> **.png**
